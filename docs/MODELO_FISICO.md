# Modelo físico Oracle

La definición ejecutable completa y autoritativa está en [01_tables.sql](../database/01_tables.sql). No se reemplaza por un esquema de otra base de datos.

- Ocho tablas con PK `NUMBER GENERATED BY DEFAULT AS IDENTITY`.
- `VARCHAR2` para nombres, correos, estados y observaciones.
- `NUMBER(12,2)` para costos, precios y pagos; `NUMBER(7,2)` para margen.
- `NUMBER(10)` para cantidades/existencia; `NUMBER(1)` para activo.
- `TIMESTAMP DEFAULT CURRENT_TIMESTAMP` para fechas.
- FK entre roles/usuarios, proveedores/productos, clientes/pedidos, usuarios/pedidos, pedidos/detalle, productos/detalle y pedidos/pagos.
- `ON DELETE CASCADE` solo entre pedidos y sus detalles.
- `UNIQUE` para rol, correo y combinación pedido/producto.
- `CHECK` de montos/cantidades, existencia no negativa, estados válidos y activo 0/1.
- Índices para proveedor, cliente, vendedor, fecha/estado, producto del detalle y pedido del pago.

El diccionario de columnas, tamaños y valores predeterminados se encuentra en [MODELO_LOGICO.md](MODELO_LOGICO.md). Las restricciones `NOT NULL`, FK y CHECK de cada tabla se ejecutan junto con su CREATE TABLE en `01_tables.sql`; no hay que duplicarlas desde `02_constraints.sql`.

Las reglas entre múltiples filas (saldo total, reserva/devolución de stock y estados finales) se aplican en servicios y transacciones. Las restricciones de Oracle complementan estas validaciones, sin sustituirlas.

Instalación: `01_tables.sql` → `03_data.sql` → crear administrador. `04_queries.sql` se consulta después. No ejecutar repetidamente los scripts sobre un esquema con información.
