# Modelo lógico y diccionario de datos

Las claves y cardinalidades se detallan en [MODELO_RELACIONAL.md](MODELO_RELACIONAL.md) y [MODELO_ER.md](MODELO_ER.md). El siguiente diccionario se corresponde con las columnas del DDL Oracle. PK/FK se indican en las relaciones documentadas; las restricciones completas están en `database/01_tables.sql`.

## roles

| Columna | Tipo | Definición / restricciones de columna |
|---|---|---|
| id_rol | `NUMBER` | GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY |
| nombre | `VARCHAR2(30)` | NOT NULL UNIQUE |
| descripcion | `VARCHAR2(200)` | Opcional |

## usuarios

| Columna | Tipo | Definición / restricciones de columna |
